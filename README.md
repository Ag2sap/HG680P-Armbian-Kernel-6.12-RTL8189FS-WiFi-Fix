# HG680P-Armbian-Kernel-6.12-WiFi-Fix
Unofficial RTL8189FS Wi-Fi fix for HG680P using the Armbian 26.11.0 Ubuntu Noble server image originally built for Amlogic S905X-B860H (kernel 6.12.114-ophub). Includes compatibility patches, automated driver build and installation, and persistent Wi-Fi module loading.
